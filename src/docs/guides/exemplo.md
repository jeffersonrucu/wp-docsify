# Guia passo a passo — exemplo

> Painel → Docsify Docs

Um guia é uma lista numerada precedida do marcador `<!-- docsify-guide -->`.
Cada item vira um passo, e a imagem do item vira a captura daquele passo.

<!-- docsify-guide -->

1. Escreva o passo em **negrito** onde o nome do botão aparecer, como faria em
   qualquer página de documentação.

2. Ponha uma imagem no item para ilustrar o passo. Ela abre ampliada com um
   clique.

3. Não use imagem quando o texto bastar: o passo continua funcionando sem ela.

4. Publique. O leitor avança com **Próximo**, assiste com **Reproduzir** ou lê
   tudo de uma vez em **Ver todos os passos**.
